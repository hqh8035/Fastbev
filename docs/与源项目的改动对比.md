# Nova FastBEV 与原版 FastBEV 改动对比

原版项目：[FastBEV: Towards Real-time Multi-view 3D Perception](https://github.com/Sense-GVT/FastBEV)（SenseTime/GVT 团队，2023）

一句话概括：原版是"多视角 + 轻量模型 + 纯检测"，本项目改成了"单目 + 冻结大模型 + 检测/分割多任务 + 嵌入式部署优化"，面向低成本采集车场景。

---

## 1. Backbone 完全替换

| | 原版 FastBEV | 本项目 |
|--|--|--|
| 架构 | ResNet / 轻量 CNN | DINOv3 双流（ViT-H + ConvNeXt-L） |
| 训练方式 | 端到端全部可训练 | 冻结大模型，只训练投射层 |
| 多视角 | 多摄像头环视（6 camera） | 单目前视 |

原版是多视角的，用轻量 backbone 处理多张图。本项目改为单目，用超大预训练模型弥补单视角信息不足。

## 2. 视角投影方式简化

| | 原版 | 本项目 |
|--|--|--|
| 投影依赖 | 内参 + 外参 + ego pose | 仅内参 |
| 坐标系 | 世界坐标系 BEV | 相机坐标系 BEV |
| 多帧融合 | 支持时序多帧 | 单帧 |

原版需要外参把多个相机对齐到世界坐标系，本项目单目直接在相机坐标系做 BEV，省去外参和 ego pose。

## 3. 新增分割分支

原版只做 3D 检测。本项目加了 `seg_grass_head`，在 2D 图像空间做树枝/障碍物分割，且不经过 BEV 投影（利用"分割是 2D 任务"的先验）。

## 4. BEV Neck 替换

原版用简单的 FPN 或轻量卷积。本项目的 `Dinov3BEVNeck` 直接复用 ConvNeXt 预训练权重的 downsample_layers + stages，大幅提升 BEV 特征质量。

## 5. Loss 体系重构

### 原版 Loss（CenterPoint 风格，纯检测）

原版 FastBEV 采用标准的 anchor-free 检测 loss，所有回归分支统一用 L1：

| Loss 项 | 类型 | 说明 |
|---------|------|------|
| center heatmap | Gaussian Focal Loss | 中心点热力图（CornerNet 风格） |
| offset | L1 Loss | 中心点亚像素偏移 |
| height | L1 Loss | 物体中心高度 |
| lwh | L1 Loss | 长宽高尺寸 |
| yaw | L1 Loss (sin/cos) | 朝向角的正弦和余弦 |

### 本项目的改动

| 改动点 | 原版 | 本项目 |
|--------|------|--------|
| Yaw loss | L1 on sin/cos | Cosine Similarity Loss（归一化后点积） |
| Center loss | 仅 Gaussian Focal Loss | 支持 gaussian / standard focal loss 切换 |
| 正样本权重 | 无 | focal loss 中加 `pos_weight`，应对正负样本极度不平衡 |
| 新增 seg loss | 无 | branch_loss（树枝分割，Focal Loss） |
| 条件计算 | 所有样本都算全部 loss | 按 `with_camera_intrinsics` / `with_seg_label` 标志位跳过缺标注样本 |
| Loss 权重 | 等权或简单权重 | 手动调参 [15, 2, 1.5, 0.3, 2.0]，基于实际 loss 量级平衡 |

### 本项目各 Loss 权重设计

```
total_loss = 15.0 × center_loss      (~0.015 原始量级，放大后 ~0.225)
           +  2.0 × offset_loss      (~0.17  → ~0.34)
           +  1.5 × height_loss      (~0.06  → ~0.09)
           +  0.3 × lwh_loss         (~0.06  → ~0.018，数据集尺寸变化小故降权)
           +  2.0 × yaw_loss         (~0.09  → ~0.18)
           +  1.0 × branch_loss      (分割 loss，独立于检测)
```

设计原则：根据各 loss 的原始数值量级做归一化，再按任务重要性微调。center_loss 权重最高（15×）是因为中心点检测是所有回归的前提——中心点找不到，其他属性再准也没用。

## 6. 数据层面

- **数据集**：原版用 nuScenes 多视角数据 → 本项目适配 Waymo + 六分自有数据（pedestrian/corner）
- **混合采样**：加权随机采样（corner 权重 7.65，重点关注困难场景）
- **部分标注训练**：有的数据只有分割标注、没有 3D 标注，也能参与训练

## 7. 量化部署适配（原版没有）

- `torch.clip` + numpy 转换绕过地平线芯片编译器的算子限制
- ONNX export 路径独立
- 固定 `target_size` / 预计算 `sampling_coords` 消除动态 shape
- 支持 Horizon J5/J6 芯片量化导出

## 8. 每层独立投影（原版是共享）

原版 FastBEV 对所有高度层用同一个投影。本项目用 `nn.ModuleList` 给每个高度层一个独立的 1×1 Conv（`proj_to_bev[y]`），让不同高度学不同的语义投影。
